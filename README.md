# Лендінг-портфоліо

Статичний сайт-портфоліо: AI-агенти, інтеграції API, сайти. Без збірки — чистий HTML/CSS/JS, працює на GitHub Pages.

## Структура

```
index.html            — головна: hero з демо-чатом агента, послуги, «Чому саме я», агенти, API, процес
sites.html            — окрема сторінка під сайти (поки порожня, під демо)
assets/css/style.css  — усі стилі; кольори в :root на початку файлу (є темна тема)
assets/js/main.js     — меню, перемикач теми, анімації, сценарій демо-чату (масив SCRIPT)
assets/img/           — сюди класти скріншоти робіт
```

## Що поміняти в першу чергу

- Картки агентів — шаблон у коментарі в секції `#agents` (index.html)
- Сценарій демо-чату — масив `SCRIPT` у `assets/js/main.js`
- Акцентний колір — `--accent` у `style.css`

## Локальний перегляд

Просто відкрий `index.html` у браузері, або:

```
python -m http.server 8000
```
