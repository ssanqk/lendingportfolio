# Лендінг-портфоліо

Статичний сайт-портфоліо: AI-агенти, інтеграції API, сайти. Без збірки — чистий HTML/CSS/JS, працює на GitHub Pages.

## Структура

```
index.html            — головна: hero з демо-чатом агента, послуги, агенти, API, процес, контакти
sites.html            — окрема сторінка під сайти (картки з фільтром)
assets/css/style.css  — усі стилі; кольори в :root на початку файлу (є темна тема)
assets/js/main.js     — меню, анімації, сценарій демо-чату (масив SCRIPT), фільтр сайтів
assets/img/           — сюди класти скріншоти робіт
```

## Що поміняти в першу чергу

- `https://t.me/your_username` → свій Telegram (index.html і sites.html)
- Цифри в hero (`15+`, `10+`) — під реальні
- Сценарій демо-чату — масив `SCRIPT` у `assets/js/main.js`
- Акцентний колір — `--accent` у `style.css`
- Скріншоти сайтів: покласти в `assets/img/` і замінити блок `<div class="mock ...">` на `<img src="assets/img/....png">`

## Локальний перегляд

Просто відкрий `index.html` у браузері, або:

```
python -m http.server 8000
```
